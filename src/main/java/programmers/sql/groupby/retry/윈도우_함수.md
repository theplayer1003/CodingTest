# 윈도우 함수

- RDB 에서 행(Tuple)의 원형을 보존하면서 특정 연산 범위 내의 데이터들에 대해 수학적 계산을 수행하는 ANSI SQL 표준 쿼리이다.

- 기본 구조는 다음과 같다.
```sql
SELECT
    FUNCTION_NAME() OVER (
    [PARTITION BY 컬럼]
    [ORDER BY 컬럼]
    [WINDOW FRAME 절]
    )
FROM 테이블;
```
- `PARTITION BY`: `GROUP BY` 와 유사한 부분으로 연산의 독립적인 경계를 설정한다. `GROUP BY` 와는 다르게 행을 압축하지 않는다.
- `ORDER BY`: 나눠진 파티션들에 대해 정렬을 설정한다.
- `WINDOW FRAME`: 파티션 내에서도 연산에 참여할 행 범위를 더 미세하게 지정한다.

- 윈도우 함수는 사용 목적을 크게 세 가지로 나눌 수 있다.

## 순위
- 나눠진 파티션에 대해 정렬된 순서로 순위를 매길 수 있다. 동점자 처리가 핵심 포인트다.

1. `ROW_NUMBER()`: 동점자를 인정하지 않는다. 물리적 스캔 순서나 정렬에 따라 무조건 고유한 일련번호를 부여한다.
2. `RANK()`: 동점자에게 동일한 순위를 부여한다. 동점자 수 만큼 순위를 건너뛰지 않는다.
3. `NTILE(N)`: 파티션 내의 행들을 N개의 버킷으로 균등하게 분할한다. 1 부터 N 까지의 등급을 부여하는 것.

## 집계
- 기존의 집계 함수, `SUM`, `MAX`, `MIN`, `AVG`, `COUNT` 에 `OVER()` 절을 붙여 윈도우 함수로 전환한다.
- 원본 행을 압축하지 않고 파티션 내의 집계 결과를 새로운 컬럼으로 만들어 덧붙인다.
- `ORDER BY` 절 까지 작성하면 윈도우 프레임이 "처음부터 현재 행까지" 로 설정되어 누적합이나 이동 평균을 구할 수 있게 된다.

## 분석
- 데이터베이스 포인트를 조작해 현재 행 기준으로 이전이나 이후 물리적 위치에 있는 튜플의 특정 컬럼값을 직접 참조하는 함수이다.

1. `LAG(컬럼, 칸수, 기본값)`: 현재 행을 기준으로 명시된 칸수만큼 이전, 즉 위에 위치한 행의 값을 가져온다.
2. `LEAD(컬럼, 칸수, 기본값)`: 현재 행을 기준으로 명시된 칸수만큼 이후, 즉 아래에 위치한 행의 값을 가져온다.
3. `FIRST_VALUE(컬럼)`: 파티션 및 윈도우 프레임 내에서 가장 첫 번째로 스캔된 행의 값을 반환한다.
4. `LAST_VALUE(컬럼)`: 파티션 및 윈도우 프레임 내에서 가장 마지막으로 스캔된 행의 값을 반환한다.

# WINDOW FRAME 절
- 파티션 내부에서 연산 대상이 되는 범위를 행 단위로 정밀하게 조정한다.

1. `UNBOUNDED PRECEDING`: 파티션의 첫 번째 행부터
2. `CURRENT ROW`: 현재 연산 중인 행 까지
3. `N PRECEDING / N FOLLOWING`:현재 행 기준 앞 N개, 뒤 N개 행
