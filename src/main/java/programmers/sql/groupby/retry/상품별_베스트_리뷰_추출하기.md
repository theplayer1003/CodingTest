# [문제] 상품별 베스트 리뷰 추출하기

**문제 설명**
다음은 어느 이커머스 플랫폼의 상품 리뷰 정보를 담은 `PRODUCT_REVIEWS` 테이블입니다. `REVIEW_ID`, `PRODUCT_ID`, `USER_ID`, `SCORE`, `CONTENT`, `CREATED_AT`은 각각 리뷰 ID(PK), 상품 ID, 작성자 ID, 평점(1~5), 리뷰 내용, 작성일시를 의미합니다.

| Column name | Type | Nullable |
| --- | --- | --- |
| REVIEW_ID | VARCHAR(10) | FALSE |
| PRODUCT_ID | VARCHAR(10) | FALSE |
| USER_ID | VARCHAR(10) | FALSE |
| SCORE | NUMBER | FALSE |
| CONTENT | VARCHAR(255) | FALSE |
| CREATED_AT | TIMESTAMP | FALSE |

**요구사항**
`PRODUCT_REVIEWS` 테이블에서 **각 상품(`PRODUCT_ID`)별로 평점(`SCORE`)이 가장 높은 리뷰**의 상품 ID, 최고 평점, 리뷰 내용, 작성일시를 조회하는 SQL문을 작성해주세요.

단, 특정 상품에 최고 평점을 받은 리뷰가 여러 개(동점자) 존재할 경우, **가장 최근에 작성된 리뷰(`CREATED_AT`이 가장 큰 값) 단 하나만** 결과 집합(Result Set)에 포함되어야 합니다.
결과는 상품 ID를 기준으로 오름차순 정렬해주세요.

**예시 데이터**
`PRODUCT_REVIEWS` 테이블이 다음과 같을 때:

| REVIEW_ID | PRODUCT_ID | USER_ID | SCORE | CONTENT | CREATED_AT |
| --- | --- | --- | --- | --- | --- |
| R01 | P001 | U100 | 5 | 정말 좋아요! | 2026-02-10 10:00:00 |
| R02 | P001 | U101 | 5 | 배송이 빠릅니다. | 2026-02-15 14:30:00 |
| R03 | P001 | U102 | 4 | 무난해요. | 2026-02-16 09:00:00 |
| R04 | P002 | U100 | 3 | 생각보다 별로네요. | 2026-01-20 11:00:00 |
| R05 | P002 | U103 | 5 | 최고입니다. | 2026-01-22 15:45:00 |

**기대 출력 결과**
P001 상품은 5점짜리 리뷰가 2개 존재하지만, 작성일시가 더 늦은 R02 리뷰의 내용이 출력되어야 합니다.

| PRODUCT_ID | SCORE | CONTENT | CREATED_AT |
| --- | --- | --- | --- |
| P001 | 5 | 배송이 빠릅니다. | 2026-02-15 14:30:00 |
| P002 | 5 | 최고입니다. | 2026-01-22 15:45:00 |
